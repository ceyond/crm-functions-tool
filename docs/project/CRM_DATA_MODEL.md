# CRM Data Model

The repository interacts with Zoho CRM functions and automation-linked functions.

## Observed entities

- CRM functions
- Automation functions
- Function execution requests

## Notes

- Field-level CRM data model details are not fully represented in this repository snapshot.
- Any entity or field mapping that is only known from Zoho configuration should stay documented as an external assumption until it is observable from source or exported metadata.
