# Utilities

This repository follows a light utility convention through the local scripts and shared config.

## Observed utility layers

- `scripts/cli-env.js` centralizes CLI environment handling.
- `scripts/zoho/*` share Zoho transport and sync helpers.
- `config/` stores shared repository settings.

## Notes

- `util_*` naming is not currently a prominent convention in this repo snapshot.
- Any shared helper behavior should stay documented here once it becomes stable and explicit.
